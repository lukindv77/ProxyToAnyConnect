# Start a new ProxyToAnyConnect chat

The canonical, maintained startup prompt is:

`docs/handoff/NEW_CHAT_PROMPT.md`

Copy the text after its separator (`---`) as the first message in the new chat. Before coding, the new chat must fetch live GitHub `main`, exact-head Actions, live issues/comments, and `dev/issue49-probe-target`; live GitHub is authoritative over archived SHA snapshots.
