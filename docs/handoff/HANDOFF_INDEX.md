# Handoff index

Read in this order:
1. `NEW_CHAT_PROMPT.md` — exact first-message prompt for a new chat.
2. `SESSION_2026-08-28.md` — detailed last-session engineering/audit record.
3. `CURRENT_STATE.md` — compact accepted architecture/current boundary.
4. `ACTIVE_DEVELOPMENT.md` — next engineering block (#49/#50 clean acceptance).
5. `DEV_ISSUE49_50_STATUS.md` — exact dev branch/run/source identities.
6. `FINAL_CI_STATUS.md` — accepted production and dev CI checkpoints.
7. `ISSUES_SNAPSHOT.md` — issue map; live GitHub is authoritative.
8. `AUDIT_SNAPSHOT.md` — latest audit conclusions.
9. `../requirements.md`, `../architecture.md`, `../memory-stability.md`.
10. Windows integration/evidence/soak docs and live Actions/issues.

The exact-head `handoff` Actions artifact is the canonical archive copy for a GitHub commit.
